# 💫 About Me

Drawing from 10 years of experience in the optical industry and fueled by a lifelong passion for technology and gaming, I ventured into the dynamic world of software and web development.

After beginning this professional transition at Wild Code School, I continued developing my skills through a 15-month Application Developer program.

Today, I work on business applications and custom solutions built around Microsoft Dynamics 365 and the Power Platform. I develop and customize model-driven applications using Dataverse, Power Apps Component Framework (PCF), TypeScript, React, and the Dynamics 365 Client API.

My recent projects include custom PCF controls, configurable multi-table lookup components, advanced Dataverse integrations, form and grid customizations, Web Resources, security-role architecture, and data-import tools.

I also develop web, API, and mobile applications using C#, ASP.NET Core, Entity Framework Core, and .NET MAUI.

With a sociable disposition, strong curiosity, and a constant desire to understand how things work, I enjoy tackling complex business requirements and turning them into maintainable technical solutions.

<br/>

## 🚀 What I currently work with

- Microsoft Dynamics 365 and Dataverse

- Power Apps Component Framework (PCF)
- Dynamics 365 Client API and `Xrm.WebApi`
- TypeScript and React
- C# and ASP.NET Core
- Entity Framework Core
- .NET MAUI mobile applications
- REST APIs and external-service integrations
- Custom grids, form scripts, Web Resources, and reusable controls
- Dataverse security roles, teams, and access management
- Automated builds and GitHub Actions
